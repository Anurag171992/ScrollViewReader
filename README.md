ScrollViewReader Demo — SwiftUI

An iOS sample project demonstrating how to use SwiftUI's ScrollViewReader for programmatic scrolling, dynamic index selection, change handling, and smooth animations.

✨ Features

TextField input for selecting an item index
ScrollViewReader proxy to programmatically scroll to specific items
Animated scrolling using .spring()
onChange handling to respond to index changes
Invalid index handling to gracefully handle unavailable items
📱 Requirements

iOS 17+
Xcode 15+
SwiftUI
🛠 Technologies

Swift
SwiftUI
ScrollViewReader
ScrollView
TextField
onChange
SwiftUI animations
